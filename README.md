# cats-dogs-ai

Estrutura inicial do projeto:

```text
dataset/
  train/
    cats/
    dogs/
  val/
    cats/
    dogs/

train.py
predict.py
cats_dogs_resnet18.pth
requirements.txt
```

- `dataset/train/`: imagens usadas para treinamento do modelo.
- `dataset/val/`: imagens usadas para validação do modelo.
- `train.py`: ponto de entrada para treinamento.
- `predict.py`: ponto de entrada para inferência.
